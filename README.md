## 📌 Problem Statement

> AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Dementia Patients in North Eastern Region (NER)

Dementia care in NER's remote, hill-terrain communities is held back by two gaps: almost no access to neurological specialists, and digital cognitive-care tools that are built for Western, urban, English-speaking users — not for elderly patients whose memories, language, and daily lives are rooted in NER's own traditions.

## 💡 What Ningsing Does

Ningsing is a single platform offering **culturally-grounded cognitive games**, designed around one core principle: **difficulty should deepen thinking, not speed up reflexes.** Making a level "harder" never means a shorter timer — it means more to hold in memory, more to filter out, and less scaffolding, so the game exercises the brain without triggering the frustration that makes elderly patients give up and disengage.

### 🎮 Core Game Modules

| Game | Mechanic | Cognitive Domain |
|---|---|---|
| **The Weaver's Pattern** | Visual pattern-completion using real Assamese Gamusa, Naga shawl, and Mizo Puanchei textile motifs | Memory & object/pattern recognition |
| **Wangala Beats** | Auditory rhythm-recall drawn from the Garo tribe's Wangala ("100 Drums") harvest festival drumming tradition | Attention & concentration |

Every session opens with a real photo/voice message from the patient's own family member — grounding gameplay in reminiscence and orientation therapy, not treating it as an isolated exercise.

## ✨ Key Features

- **Culturally authentic content** — built on real, documented NER traditions, not generic reskinned puzzles
- **Adaptive difficulty** — designed to respond to how a patient is actually performing (accuracy, response time, retries), not push a fixed difficulty curve
- **Caregiver visibility** — a simple way for family/health workers to check in on how a patient is doing, without adding complexity for the patient
- **Offline-first vision** — designed for NER's real connectivity constraints, so core functionality doesn't depend on a live internet connection

## 🖥️ About This Prototype

This repository hosts our **hackathon prototype** — a static HTML/CSS/JS build demonstrating the core game experience and UI, deployed via GitHub Pages for quick, zero-install evaluation.

Our full proposed architecture (Flutter app, FastAPI backend, PostgreSQL, and a Random Forest ML engine for adaptive difficulty and decline-risk scoring) is detailed in our pitch deck — this prototype focuses on proving the game mechanics and design direction rather than the full production stack.
